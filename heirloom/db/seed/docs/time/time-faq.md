# Time & Attendance FAQ

**Can employees edit their own punches after submitting a timesheet?**
No. After submission, only a manager can edit punches, and the edit requires re-approval.

**Does PTO accrue during unpaid leave?**
No.

**What happens to missed punches?**
The timesheet is flagged and the manager must add the punch before approval.
